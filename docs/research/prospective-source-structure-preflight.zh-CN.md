# 第四案例来源结构预检

## 决策

**本次限额预检两个候选均为 NO-GO，不创建第四案例或有效预注册。** 尚未检查的来源谱系、熟悉的地名清单和地图集的宽泛覆盖范围，都不能满足硬门槛。本结果仅判断本次预算内实际证明的可行性，不意味着两个题目在历史材料上无法成立。

[机器可读审计](prospective-source-structure-preflight.json)保留原始查询、访问尝试、七维来源矩阵、rights、排除项、比较资料元数据、偏差及计算结果。此前未提交的 Amarna 框架错误宣告 GO，已在任何 commit 前撤回，同时撤回草拟的冻结清单和未使用的相对阶段 schema 扩展。未预注册研究问题、评价分母或书信阶段。

Florence–Siena 有十二个具名候选，包括 Poggibonsi、Colle、San Gimignano、Volterra、Monteriggioni；地点识别未独立核验。较早事件不能直接沿用至 1259 年。已读目录中的 Poggibonsi 市政档案始于 1314 年，Monteriggioni 始于 1566 年；其他中世纪档案系列虽存在，本轮没有检查目标年份的具体文书。因此，1259 年末管辖状态及稳定中心影响模型的适用性仍未证实。[锡耶纳档案目录](https://archiviodistatosiena.cultura.gov.it/home/patrimonio/fondi-archivistici/elenco-dei-fondi/c)、[佛罗伦萨 Diplomatico](https://www.archiviodistato.firenze.it/asfi/archivi-digitalizzati/diplomatico/)。

## 访问、rights 与排除项

每个候选保留六个初步来源记录、六次明确检查。实际证明的完整正文访问率：**Amarna 为 1/6**（五次 ORACC 502，仅 UCL 指南成功获取）；**Florence–Siena 为 3/6**（Villani 两个版本及 Gardner；两个目录和一份出版商节选不计入分子）。索引文字可提供线索，不能登记为正文获取成功。保守分母保留失败记录，不评价其他合法渠道的可获得性。[UCL 语料指南](https://www.ucl.ac.uk/museums-static/digitalegypt/amarna/cuneiform2.html)、[Villani 英译](https://www.gutenberg.org/files/33022/33022-h/33022-h.htm)。

AEMW 的 CC BY-SA 3.0 声明见于 EA 136 索引版本，其他声明未直接获取。UCL 保留版权；意大利档案目录与 Laterza 节选可读，但未证明无限制复用权。Gutenberg 提供美国公有领域访问路径，不能据此认定全球再分发权。仓库仅保存引用和原创转述，不纳入扫描件、来源正文或图片。[EA 136 版本](https://oracc.museum.upenn.edu/aemw/amarna/P270902/html)、[Laterza 节选](https://www.laterza.it/scheda-libro/?isbn=9788858134832)。

Amarna 保留子辈阶段混入与来源地不确定两项排除。Florence–Siena 保留较早日期回投、军事事件与控制关系混淆、晚期档案系列误用等排除。两者均未证明稳定阶段、十二个已核验地点识别、每中心两条政治谱系，以及预计能表达至少十个单元的合适比较资料。未授权 XTENT 输入；compiler、diagnosis 和 backend 行为保持不变。

## 隔离与预算审计

每个候选使用了**八次研究查询加一次元数据查询**。按包含元数据的总查询口径为 **9/8**，元数据子预算为 **1/2**。Florence–Siena 元数据响应意外返回**三部地图集**，按保守口径也超出两候选上限。超额如实记录，纠正后未增加查询。

Amarna 元数据线索为 Bryce 与 Birkett-Rees 的 2016 年地图集，OCLC 898926342。宽泛范围无法证明其适于十个短时段评价单元。没有打开地图集目录链接、地图、缩略图或图版。Florence–Siena 的三部意外地图集均因搜索响应含封面图像标记而被排除；这些标记本身不能证明看过地图像素。[Amarna 比较资料目录元数据](https://search.worldcat.org/title/atlas-of-the-ancient-near-east-from-prehistoric-times-to-the-roman-imperial-period/oclc/898926342)。

没有使用 image search、截图、OCR、矢量请求或地图文件存储，没有主动选择或使用已知疆域地图主体。但曾通过文本读取器打开带插图的 Gutenberg 整书 HTML，事先未按章节隔离；返回段落为叙述文本。因此，本审计不宣称浏览过程已得到完美控制或能全面证明零暴露。仓库检查无法认证完整浏览历史。
